# Changelog

### Added
- 🎨 **Liquid Glass Design System** - Modern glassmorphism UI with 6 presets
- ✨ Rebranded from AyuGram to Overgram
- 📱 Android 12+ native blur support using RenderEffect API
- ⚡ GPU-accelerated blur rendering for 60 FPS performance
- 🎯 Customizable glass parameters (blur, opacity, saturation, tint)
- 🔧 New settings section for Liquid Glass customization
- 📊 Battery-aware mode for blur effects

- 🔧 Performance optimizations

## [1.0.0] - TBD

### Initial Overgram Release

Based on AyuGram4A with full rebrand and new features.

**Core Features:**
- Full Ghost Mode (hide online, read receipts, typing)
- Message History Database (save edits and deletions)
- Anti-Recall (keep deleted messages)
- Local Telegram Premium
- Message Filters
- No Ads
- Screenshots in secret chats
- No emulator detection

**From exteraGram:**
- Material You theming
- Custom fonts
- Advanced chat customization
- Enhanced media viewer

**From Telegraher:**
- Official API keys
- Privacy patches
- TTL media controls
